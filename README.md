# Сайт-визитка Камиля

Обычный статический сайт: `index.html`, `css/style.css`, `js/main.js`, `img/`. Сборка не нужна.

## Где что менять

- **Telegram и Профи.ру** — объект `CONFIG` в начале `js/main.js`.
- **Отзывы в бегущей ленте** — массив `REVIEWS` там же. Поле `tag` — плашка с результатом, её можно не заполнять.
- **Скриншоты отзывов.** Файлы лежат в `img/proofs/`. Чтобы добавить новый, скопируй любой блок `<figure class="proof">` в `index.html`.
- **Фото:**
  - `img/hero.jpg` — первый экран;
  - `img/about.jpg` — «Обо мне»;
  - `img/features.jpg` — «Что ты получаешь»;
  - `img/booking.jpg` — запись;
  - `img/gallery/01–14.jpg` — галерея.
- **Цены, тексты, FAQ** — прямо в `index.html`.

После правок в CSS или JS увеличь номер версии в `index.html` (`style.css?v=4` → `?v=5`). Иначе браузеры могут показать старую версию из кэша.

## Как посмотреть локально

```bash
python3 -m http.server 5173
```

Потом открыть http://localhost:5173

## Как выложить бесплатно

**Самый быстрый способ — Netlify Drop.** Открой https://app.netlify.com/drop и перетащи туда папку `kamil-site`. Сразу получишь ссылку; домен можно поменять в настройках.

**GitHub Pages.** Создай репозиторий и загрузи в него файлы. Затем открой Settings → Pages → Deploy from branch → `main` / root.

После публикации поменяй в `index.html` строку `og:image` на полный адрес картинки, например `https://твой-сайт/img/hero.jpg`. Тогда превью ссылки в мессенджерах будет с фото.
